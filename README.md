# CreditIQ — Raw Data

## 1. Dataset

CreditIQ uses the **Home Credit Default Risk** dataset from Kaggle.

The dataset contains seven related tables describing:

- Loan applications
- Previous credit history
- Previous Home Credit applications
- Repayment behavior
- POS/cash-loan history
- Credit-card history

The raw files are kept unchanged during the data-acquisition stage.

---

## 2. Data Source

**Source:** Kaggle — Home Credit Default Risk

The dataset can be downloaded using the Kaggle CLI:

```bash
kaggle competitions download -c home-credit-default-risk
